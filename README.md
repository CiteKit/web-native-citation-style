# Web-Native Citation Style

**An open citation style for digital and traditional sources.**

Web-Native uses numbered in-text citations and a title-first Sources list. It provides a consistent way to cite websites, articles, books, research, videos, podcasts, software, datasets, and other published works.

**Version:** 0.5 (draft)  
**Created by:** CiteKit Publishing Technologies  
**Format:** Citation Style Language (CSL) 1.0.2

## How It Works

### In-text citations

References use numbers enclosed in square brackets.

The first source cited is `[1]`, the next is `[2]`, and so on. Each source keeps its assigned number throughout the document.

When citing multiple sources together, use separate brackets: `[1][5]`, not `[1, 5]`.

**Example**

The first study established the method [1]. Subsequent research supported its findings [1][2].

### Sources list

Each cited source appears once, in the order it was first cited.

**Example**

1. Source Management for Web Publishers. https://example.org/guide. John Michael Smith. Example Publishing. Published: January 15, 2024. Accessed: October 10, 2026

2. The Archive and the Evidence. Anna Marie Walker. Example Academic Press. Published: 2020

*These examples use fictional sources.*

References follow this field order:

**Title → URL → Creators → Publisher or publication → Published date → Accessed date**

Missing information is omitted. Personal names appear in their full available form and natural reading order. Contributors such as editors, directors, and narrators are identified by role.

## Citation Guide

The [Web-Native Citation Style Guide](https://citekit.com/web-native-citation-style/) provides citation rules, reference formats, and examples for 15 source types, including websites, journal articles, books, reports, films, podcasts, and software.

## Download and Installation

**[Download Web-Native Citation Style (.csl)](./web-native-citation-style.csl)**

To install:

1. Download the CSL file.
2. Open a reference manager or citation application that supports custom CSL styles.
3. Import the file and select Web-Native as your citation style.

Web-Native can be used without CiteKit software.

## Compatibility

Web-Native is implemented in CSL 1.0.2 and has passed the [official CSL validator](https://validator.citationstyles.org/) without errors.

Applications that support custom CSL styles can use the file to format citations and bibliographies. Output depends on the bibliographic information provided and the application's CSL support.
